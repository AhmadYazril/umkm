# TAHAP 8: KEAMANAN DAN KEBUTUHAN NON-FUNGSIONAL
**Proyek:** Sistem Informasi Profil dan E-Order Nucomu Cafe (Laravel)
**Fokus Analisis:** Arsitektur Keamanan, Integritas Data, dan Evaluasi Bukti Kinerja

---

## 1. Matriks Implementasi Aspek Keamanan dan Non-Fungsional

| No | Aspek Keamanan & Non-Fungsional | Implementasi Teknis di Kode | Bukti Berkas & Lokasi Baris |
|---|---|---|---|
| 1 | **Autentikasi Multi-Peran** | Sistem memisahkan pintu masuk login untuk masing-masing aktor: Admin menggunakan kombinasi email dan password (`Auth::attempt`), Staf Kasir menggunakan login cepat kata sandi kasir, dan Kurir menggunakan verifikasi PIN 4-6 digit. | - `app/Http/Controllers/Admin/AuthController.php` (L68-112)<br>- `app/Http/Controllers/KasirController.php` (L235-265)<br>- `app/Http/Controllers/ZendoTrackingController.php` (L130-185) |
| 2 | **Nama & Mekanisme Cookie Otentikasi** | Menggunakan cookie persisten bertanda tangan digital (*signed cookie*) berbasis HMAC SHA-256 dengan secret key `config('app.key')`.<br>- Admin: `nucomu_admin_auth_v1` (masa aktif 30 hari).<br>- Kasir: `nucomu_kasir_auth_v2` (masa aktif 365 hari / 1 tahun).<br>Verifikasi integritas token menggunakan fungsi tahan serangan waktu (*timing-attack safe*) `hash_equals()`. Cookie disetel `HttpOnly=true` dan `SameSite=Lax`. | - `app/Http/Controllers/Admin/AuthController.php` (L17-55)<br>- `app/Http/Controllers/KasirController.php` (L38-85)<br>- `app/Http/Middleware/AdminMiddleware.php`<br>- `app/Http/Middleware/KasirMiddleware.php` |
| 3 | **Hashing Kata Sandi** | Seluruh kata sandi pengguna (Admin dan Kasir) dienkripsi satu arah menggunakan algoritma **Bcrypt** standar industri melalui fasad `Hash::make()` dan diverifikasi melalui `Hash::check()`. Tidak ada kata sandi yang disimpan dalam format teks polos (*plaintext*). | - `app/Http/Controllers/Admin/AuthController.php`<br>- `app/Http/Controllers/Admin/ProfileController.php` (L75-85)<br>- `database/seeders/DatabaseSeeder.php` |
| 4 | **Proteksi Pemalsuan Permintaan Antar-Situs (CSRF)** | Framework Laravel secara otomatis memvalidasi token CSRF pada seluruh permintaan HTTP `POST`, `PUT`, `PATCH`, dan `DELETE` melalui middleware grup `web`. Setiap formulir Blade menyertakan direktif `@csrf`, dan panggilan JavaScript menyertakan header `X-CSRF-TOKEN`. | - `resources/views/admin/auth/login.blade.php`<br>- `resources/views/kasir/login.blade.php`<br>- `resources/views/components/cart-drawer.blade.php`<br>- `routes/web.php` |
| 5 | **Validasi & Sanitasi Masukan (*Input Validation*)** | Semua input pengguna divalidasi ketat di sisi server melalui `$request->validate()` dengan aturan tipe data, batas panjang karakter (`max`), keberadaan nilai (`required`), dan format berkas. Tampilan Blade menggunakan sintaks kurung kurawal ganda `{{ $var }}` yang otomatis mengeksekusi `htmlspecialchars()` untuk mencegah serangan *Cross-Site Scripting* (XSS). Parameter query basis data menggunakan PDO parameter binding yang kebal terhadap *SQL Injection*. | - `app/Http/Controllers/NucomuController.php` (L1753-1774)<br>- `app/Http/Controllers/Admin/MenuController.php` (L45-70)<br>- `app/Http/Controllers/Admin/ProfileController.php` (L31-48) |
| 6 | **Keamanan Unggah Berkas (*File Upload Security*)** | Berkas gambar yang diunggah (avatar, menu, banner, bukti ulasan) diuji tipe MIME-nya (`image|mimes:jpg,jpeg,png,webp`) dan dibatasi maksimal 2048 KB (2 MB). Nama berkas di-*rename* secara acak menggunakan pola unik berbasis waktu `time()` dan ekstensi asli yang divalidasi, disimpan di direktori publik dengan bantuan `FileUploadHelper::ensureDirectoryWritable()` untuk mencegah eksekusi skrip berbahaya (.php/.sh). | - `app/Support/FileUploadHelper.php`<br>- `app/Http/Controllers/Admin/MenuController.php`<br>- `app/Http/Controllers/Admin/BannerController.php`<br>- `app/Http/Controllers/Admin/ProfileController.php` (L50-65) |
| 7 | **Otorisasi Berbasis Peran (*Role-Based Access Control - RBAC*)** | Pemisahan hak akses ditegakkan oleh dua middleware khusus: `AdminMiddleware` memastikan peran pengguna adalah `'admin'`, dan `KasirMiddleware` memastikan peran pengguna adalah `'kasir'`. Pengguna biasa tanpa hak akses ditolak dengan respon HTTP 403 Forbidden atau diarahkan ke halaman login. | - `app/Http/Middleware/AdminMiddleware.php`<br>- `app/Http/Middleware/KasirMiddleware.php`<br>- `app/Models/User.php` (`isKasir()`, `isAdmin()`) |
| 8 | **Integritas Transaksi Atomik (`DB::transaction`)** | Seluruh proses penulisan data yang melibatkan multi-tabel dibungkus di dalam penutupan atomik `DB::transaction(...)`. Jika salah satu langkah gagal (misal pembuatan `order_items` error), seluruh mutasi data otomatis dibatalkan (*rollback*) ke kondisi semula sehingga integritas keuangan tetap terjaga. | - `app/Http/Controllers/NucomuController.php` (L1848-1891)<br>- `app/Http/Controllers/KasirController.php` (L560-585) |
| 9 | **Pembatasan Frekuensi Permintaan (*Rate Limiting*)** | **Kondisi Aktual di Kode:** Proyek ini tidak memiliki berkas rute terpisah `routes/api.php` dan tidak menerapkan middleware `throttle:60,1` pada rute `routes/web.php`. Seluruh rute dilindungi oleh middleware grup `web` standar. Hanya terdapat batas timeout 4 detik pada pemanggilan HTTP API Google Places eksternal. | - `routes/web.php`<br>- `app/Http/Controllers/NucomuController.php` (L272, `Http::timeout(4)`) |
| 10 | **Responsivitas Lintas Perangkat (*Responsive Design*)** | Antarmuka pengguna dibangun secara *mobile-first* menggunakan utility class responsif Tailwind CSS v4 (`sm:`, `md:`, `lg:`, `xl:`), tag meta viewport `<meta name="viewport" content="width=device-width, initial-scale=1.0">`, dan transisi CSS interaktif. Antarmuka teruji proporsional pada layar ponsel pintar (360px) hingga monitor desktop (1920px). | - `resources/views/layouts/app.blade.php`<br>- `resources/views/layouts/admin.blade.php`<br>- `resources/views/components/cart-drawer.blade.php`<br>- `public/css/nucomu.css` |
| 11 | **Penyimpanan Sisi Klien (*Client-Side LocalStorage*)** | Keranjang belanja mandiri pelanggan dan keranjang transaksi POS kasir disimpan sementara pada peramban pengguna menggunakan API `window.localStorage` (kunci `nucomu_cart` dan data katalog). Ini memungkinkan keranjang tidak hilang saat halaman disegarkan (*refresh*) tanpa membebani sesi server. | - `resources/views/components/cart-drawer.blade.php` (L980-1050)<br>- `resources/views/kasir/index.blade.php` (L420-480) |
| 12 | **Klaim Kinerja & Waktu Muat (*Performance Claims*)** | **Status Pengukuran:** **TIDAK DITEMUKAN PENGUKURAN DI PROYEK**.<br>Tidak ditemukan instrumen tolok ukur (*benchmarking*), uji beban (*load testing*), skrip Lighthouse CI, maupun pengujian waktu muat di bawah 2 detik di dalam folder pengujian `tests/`. Berdasarkan kaidah analisis perangkat lunak yang objektif, klaim waktu muat belum dapat disahkan secara empiris sebelum dilakukan pengujian langsung pada jaringan rill. | - Folder `tests/` (Hanya memuat pengujian fungsional fitur, tidak memuat uji waktu respon) |
